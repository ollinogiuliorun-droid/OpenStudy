# OpenStudy

OpenStudy is a small, open-source browser app for collecting and organizing study links by subject. It is an early prototype intended to explore simple, accessible learning-resource organization.

## Features
- Add resources with a title, URL, and category
- Search saved resources
- Remove resources
- Stores data in the browser's local storage (no account or server required)

## Run it
Download or clone this repository and open `index.html` in a browser. No build step is required.

## Privacy
Resources are stored locally in the browser using local storage. This prototype does not send resource data to a server.

## Project status
Early prototype. Contributions, bug reports, and suggestions are welcome.
